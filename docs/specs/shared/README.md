them are the ThoughtForge/MindSpark cognition corpus — a sibling
project's material that was parked inside WYRD's spec tree (it is

`mind-wiring.md`, `verdandi-nerve-feed.md`,

re-homed to its own project. That move is **blocked pending a
destination decision**: no destination project/repo exists yet, and
the content is preserved here, byte-for-byte, until one is named.
Do not cite these files as WYRD design truth.
